* Status and objective

This document proposes a deliberately restricted transaction loop for
TxCubicle.  The first objective is to verify =examples/german_looped.cub= with a
direct cube-level predecessor for an iterated transition.  It is not a proposal
for arbitrary cyclic transaction graphs or for compiling a general transitive
closure into a two-state transition relation.

The experimental feature is enabled only by:

#+begin_src text
-tx bwd+loop
#+end_src

The existing =-tx bwd= mode retains its current acyclic input class and
behavior.  Forward transaction exploration and =-tx all= do not support loops
in the first implementation.  A loop in any mode other than =bwd+loop= is a
located unsupported-feature error, not a verification verdict.

The central operation is

\[
  \operatorname{Pre}_{t^*}(C),
\]

where $C$ is a Cubicle cube obtained after the acyclic suffix and exit
transition have already been pre-imaged.  The keystone is a finite-relevance
theorem: for the initial transition class, process variables already in scope
plus at most one fresh process suffice to represent this starred predecessor.
The accepted fragment is chosen so that this bound has a direct proof.

The current implementation does not support loop acceleration.  It rejects
every trigger cycle and has no =bwd+loop= mode.  It does implement the
callee-tuple underscore rule used below.

* Language and control semantics

** The =loop= continuation

A unary triggered transition may offer =loop= among its continuations:

#+begin_src cubicle
triggered
transition inv_shr(i)
requires { Shr[i] = True && Curcmd = Reqe } {
  Exg := False;
  Cache[i] := Invalid;
  Shr[i] := False
}
triggers gnt_excl(_) or loop
#+end_src

For a transition =t(i)=, =loop= is syntactic sugar for a self-call =t(_)=.
After each successful turn, the self-call and the other continuations are
ordinary nondeterministic alternatives.  The self-call has no priority.  Each
selected transition must satisfy its guard; a failed branch contributes no
completed transaction.  An infinite internal execution exposes no transaction
boundary.

Consequently, a loop node followed by an exit denotes guarded Kleene-star
iteration before that exit.  A caller that offers both the loop transition and
the exit supplies the zero-turn case.  In the German example the two shapes are:

#+begin_src text
req_excl(r); gnt_excl(r)
req_excl(r); inv_shr(i); inv_shr*; gnt_excl(r)
#+end_src

Thus the self-loop after the first =inv_shr= represents zero or more additional
turns; the complete positive branch contains one or more turns.

This remains transaction-boundary semantics.  =-tx bwd+loop= does not establish
safety at intermediate ATS states inside the transaction.

** Underscores constrain the callee tuple

Consider a call

\[
  t_1(\vec x)\;\texttt{triggers}\;t(\vec a),
\]

where $\vec a$ contains named actuals and underscores.  Resolve the named
actuals, then choose values for the underscores so that the complete ordered
callee tuple $\vec a$ is pairwise distinct.  There is no inequality with caller
arguments omitted from $\vec a$.

For example, =t1(x,y,z) triggers t2(x,_,_)= produces =t2(x,u,v)= with

\[
  x\ne u,\qquad x\ne v,\qquad u\ne v,
\]

but $u$ and $v$ may reuse $y$ or $z$ when those inequalities permit it.  A
unary call =t1(x) triggers t2(_)= imposes no inequality between the selected
argument and $x$.  Separate calls may therefore reuse any earlier process when
the callee tuples remain well formed.

In particular, the implicit unary self-call =t(_)= may select the process used
by the preceding turn.  For the initial supported fragment that attempted turn
then fails, because the transition is self-disabling.  No additional
cross-iteration distinctness constraint is part of the loop semantics.

This rule replaced the former caller-argument exclusion rule and has focused
forward and backward regressions.  The loop proof below relies on it when
compressing several unnamed turns to one.

* Backward decomposition

Suppose a transaction branch has the shape

\[
  P\;;\;t^*\;;\;E\;;\;S,
\]

where $P$ and $S$ are acyclic prefix and suffix fragments and $E$ is an exit
transition.  Backward search computes

\[
  C_{bad}
  \mapsto{\operatorname{Pre}_S}
  C_1
  \mapsto{\operatorname{Pre}_E}
  C
  \mapsto{\operatorname{Pre}_{t^*}}
  C_0
  \mapsto{\operatorname{Pre}_P}
  \cdots.
\]

The input $C$ to the starred transformer already represents loop-exit states
from which the ordinary exit and suffix can reach the unsafe predicate.  There
is no additional loop postcondition and no separate universal cleanup predicate
to reconstruct.  Exit guards are handled by the ordinary transition-level
pre-image before acceleration starts.

For one process instance $i$, retain the existing operation

\[
  \operatorname{Pre}_i(X)(a)
  := \exists a'.\,R_i(a,a')\land X(a'),
\]

where $R_i$ contains the complete guard and update relation of =t(i)=.  The loop
algorithm composes this existing operation on selected arguments; it does not
reimplement transition substitution.

* Initial supported transition class

The following is a semantic class with a conservative mechanical recognizer.
It is intentionally broader than the names and concrete types in the German
example, but narrower than all transitions whose closure might be definable.

Let =t(i)= have one process argument.  Write $G_i$ for its guard and $U_i$ for
its deterministic update.

1. *One local process.* Every array access in the guard and update is of the
   form =A[i]= for a unary process-indexed array.  There is no access at another
   process, no universal loop-body guard, and no multi-process array access.
2. *Deterministic local effect.* The transition has no nondeterministic update.
   It writes only cells =A[i]=; every other process cell is unchanged.
3. *Separated globals.* Let $G_r$ be the globals read by the guard or any update
   right-hand side, and $G_w$ the globals written by the transition.  Require
   $G_r\cap G_w=\varnothing$.
4. *Constant shared writes.* Every global in $G_w$ is assigned a fixed literal
   constant, independent of the state and of $i$.  Every successful turn writes
   the same tuple of constants.
5. *Self-disabling.* A successful turn falsifies its own guard:

   \[
     R_i(a,a')\Longrightarrow \neg G_i(a').
   \]
6. *Unobserved current argument at exit.* A non-loop continuation of =t(i)=
   does not pass =i= as a named actual.  Its underscores are resolved by the
   callee-tuple rule.  Thus the exit choice does not observe which process made
   the final loop turn.

The first recognizer may establish self-disabling through a syntactic guard
literal forced false by the update, such as =Shr[i] = True= together with
=Shr[i] := False=.  This is a conservative proof rule, not the representation
used by the accelerator.  Later recognizers may establish the same semantic
property differently without changing the starred algorithm.

These restrictions imply the properties needed below.  For $i\ne j$:

- $R_i$ preserves whether $G_j$ holds;
- $R_i;R_j=R_j;R_i$ as guarded relations;
- after a successful $R_i$, no later distinct-process turn can re-enable $i$;
- every successful loop word uses each concrete process at most once.

The implication must be checked from the accepted syntax rather than assumed
from these names.  A transition outside the recognizer is unsupported even if a
human can see that it belongs to a larger accelerable class.

* Finite relevance

** Observable process set

Let $C(\vec x)$ be the target cube.  Its variables $\vec x$ denote pairwise
distinct processes.  Let $\vec k$ contain the distinct process identities
retained by the surrounding transaction context.  Reuse one representative
when a target and context identity are already known to coincide, and define

\[
  N := \{\vec x\}\cup\{\vec k\}.
\]

For a concrete state $a$, let $\pi_N(a)$ retain:

- every global value; and
- every array cell =A[n]= for $n\in N$.

The target cube depends only on this projection.  A process outside $N$ is
called unnamed relative to this predecessor problem.

** One-fresh-process lemma

*Lemma.*  Assume the initial supported transition class and the underscore
semantics above.  A /loop word/ here is only the sequence of =t(_)= turns; its
exit transition has already been pre-imaged and, by condition 6, does not name
the final iterator.  For every finite process domain $D$, every $N\subseteq D$,
every state $a$, and every legal finite loop word $w$, there is a legal word
$\widehat w$ such that:

1. $\widehat w$ uses each process in $N$ at most once;
2. $\widehat w$ contains no process outside $N$ when $w$ contains none;
3. $\widehat w$ contains exactly one process outside $N$ when $w$ contains at
   least one; and
4. the final states agree on the observation:

   \[
     \pi_N(w(a))=\pi_N(\widehat w(a)).
   \]

*Proof.*  Self-disabling and enabledness preservation imply that a successful
word already uses every concrete process at most once.  By commutation, reorder
it into its subsequence over $N$ followed by its subsequence outside $N$ without
invalidating a guard.

If the unnamed subsequence is empty, keep the named subsequence.  Otherwise,
choose one process $q$ from it and delete all other unnamed turns.  The retained
turn at $q$ was enabled in the original word.  Enabledness non-interference and
commutation make it enabled after the retained named subsequence as well.

Deleting the other unnamed turns changes only their own local cells, which
$\pi_N$ does not observe.  One retained unnamed turn performs exactly the same
constant shared-global assignments as the entire nonempty unnamed subsequence.
It does not affect the local results of named turns.  The two final projections
are therefore equal.

Finally, a unary =t(_)= call imposes no inequality with the previous turn, and
the exit does not name the final iterator.  The compressed word is therefore
accepted by the transaction control.  Every retained turn satisfies its
ordinary guard, hence the word is a concrete legal execution.  This proves the
four claims.  QED.

The converse required for precision is immediate: a generated word using one
fresh representative denotes an ordinary concrete loop word whenever its
ordinary transition pre-image is satisfiable.

The lemma is an observational compression result, not equality of complete
final states.  Deleted unnamed turns may leave different values in unnamed
cells; those values cannot affect $C$, a retained turn, or a supported shared
effect under the stated assumptions.

** Starred predecessor theorem

Let $N=\{n_1,\ldots,n_m\}$.  Define

\[
  \operatorname{Close}_i(X)
  := X\lor\operatorname{Pre}_i(X).
\]

For one fresh process variable $q$ distinct from every member of $N$, define

\[
\begin{aligned}
  X_N
    &:= \operatorname{Close}_{n_1}\circ\cdots\circ
        \operatorname{Close}_{n_m}(C),\\
  X_{fresh}
    &:= \exists q.\,
        \left(\bigwedge_{n\in N}q\ne n\right)
        \land \operatorname{Pre}_q(X_N).
\end{aligned}
\]

Then, over every finite process domain,

\[
  \operatorname{Pre}_{(\bigcup_{i\in D}R_i)^*}(C)
  \equiv X_N\lor X_{fresh}.
\]

For coverage, take a concrete witnessing word and apply the one-fresh-process
lemma.  Its retained subset of $N$ is represented by the corresponding choices
inside the =Close= composition.  If it has an unnamed turn, instantiate $q$ by
that process and take the fresh branch.  For precision, every =Close= choice and
the optional fresh branch is a composition of ordinary guarded transition
pre-images and therefore has a concrete loop word.  Pairwise commutation makes
the fixed order of the =Close= composition immaterial.

If $D\setminus N$ is empty, the distinctness constraints make the fresh branch
unsatisfiable, as required.  If the target does not observe a written global,
the fresh branch normally strengthens an already present zero-turn branch only
with the guard of =t(q)= and is removed by subsumption.  Thus one is a uniform
upper bound; some cubes need no fresh representative.

This theorem is the boundary between the accepted fragment and acceleration
complexity.  Relaxing a restriction is acceptable only with a new finite bound
and a replacement proof.

* Cube-family algorithm

Represent a disjunction by a finite family of cubes.  Let =reduce= perform only:

- removal of inconsistent cubes; and
- removal of a cube whose represented state set is included in that of another
  cube, using an existing sound Cubicle subsumption test.

This is minimization under represented-state inclusion, not optimization under
a numeric metric.

Given a target family initially containing $C$:

1. Build $N$ from the cube variables and transaction-context representatives.
2. For each $n\in N$, compute the ordinary one-step pre-images of the current
   family under =t(n)= and set

   \[
     X\leftarrow\operatorname{reduce}
       \bigl(X\cup\operatorname{Pre}_n(X)\bigr).
   \]

3. Introduce one process variable $q$ distinct from $N$.  Compute the positive
   unnamed branch $Y:=\operatorname{Pre}_q(X)$ with the ordinary one-step
   machinery.
4. Return =reduce(X union Y)=.

Step 3 must introduce one fresh representative once.  It must not call ordinary
relevant-instance generation recursively: doing so could manufacture an
unbounded sequence of fresh variables and would not implement the theorem.

The algorithm is independent of German variable names.  Its inputs are a typed
transition, a target cube family, the retained transaction representatives, and
the footprint/self-disabling facts produced by the recognizer.

* Transaction integration

The trigger graph should treat =loop= as a distinguished continuation, not as
an ordinary edge enumerated by acyclic path collection.  Only a unary
self-loop accepted by the recognizer is supported; every other cycle remains a
typing error.

Backward scheduling proceeds as follows:

1. Enumerate the acyclic transaction skeleton and preserve its shared process
   substitution as today.
2. Pre-image the suffix and exit transitions with the ordinary path machinery.
3. At a loop marker, apply the cube-family starred transformer to the remaining
   target cubes.
4. Pre-image the current invocation of the loop transition once.  This accounts
   for the mandatory first turn on a positive branch; the star accounts for its
   additional turns.
5. Continue through the acyclic prefix.  Only future-free cubes return to the
   ordinary backward queue.

The zero-turn transaction branch is the caller's direct edge to the exit, not a
fabricated successful execution of the loop transition.  A failed first turn
therefore still rolls back the positive branch.

The exact shape of loop metadata in transaction futures is an implementation
question.  It must preserve the existing invariant that intermediate cube
variables and the stored transaction substitution refer to the same names.

* German instance

For =inv_shr(i)=,

\[
  G_i(a)
  \equiv
  \mathit{Shr}[i]=\mathsf{True}
  \land \mathit{Curcmd}=\mathsf{Reqe}.
\]

One turn performs

\[
  \mathit{Shr}[i]:=\mathsf{False},\qquad
  \mathit{Cache}[i]:=\mathsf{Invalid},\qquad
  \mathit{Exg}:=\mathsf{False}.
\]

It belongs to the initial class:

- all local accesses are at $i$;
- the update is deterministic;
- =Curcmd= is read and not written;
- =Exg= is written with a constant and not read by the loop;
- writing =Shr[i] := False= falsifies the local guard;
- different process turns preserve each other's guards and commute.

The ordinary backward pre-image of =gnt_excl(r)= is computed before the loop
closure.  Its ordinary and universal guards therefore contribute through the
existing transition-predecessor operation; the loop rule has no special
=forall_other= case.

For a loop-exit cube with relevant set $N$, turns at members of $N$ account for
changes to named =Shr= and =Cache= cells.  If a positive turn at an unnamed
process is relevant because it establishes =Exg = False=, the one fresh
representative supplies its guard and shared effect.  Any additional unnamed
invalidations have no further effect on the cube projection and are compressed
by the lemma.

Under the revised underscore rule, =inv_shr(i) triggers gnt_excl(_)= permits the
grant argument to equal $i$: the callee has one argument, so its actual tuple is
automatically pairwise distinct.  The previous first/last-iteration ordering
problem does not arise.

This establishes that German is inside the proposed semantic fragment.  It is
not yet evidence that the current cube implementation realizes the theorem or
that the example verifies; those require the implementation and tests below.

* The fragment/complexity frontier

The one-fresh bound fails or requires a different proof when an extension makes
the number or identities of unnamed turns observable.  The following are
outside the first fragment.

| Relaxation | Likely additional requirement |
|------------+-------------------------------|
| A loop transition has several process arguments | Enough fresh representatives for one or more distinct callee tuples |
| Calls impose inequalities across iterations | Representatives sufficient for a legal compressed word |
| An exit names the final loop argument | A distinguished final-turn representative and constrained canonical order |
| A turn changes another process's enabledness | Dependency/order analysis; no subset factorization in general |
| Shared writes depend on local state | One representative per distinguishable shared effect, if finite |
| Shared updates count, toggle, or accumulate | A saturation bound or an aggregate acceleration; possibly no finite bound |
| A target observes cardinality or a universal array property directly | A richer symbolic target and a new relevance theorem |
| A process can execute successfully more than once | A uniform local saturation bound and repeated per-process pre-images |
| Nondeterministic updates have several observable effects | Relational effect classes and enough witnesses for their combinations |

This table is a research map, not a promise that every row admits an exact
extension.  The Pareto frontier should be explored by relaxing one condition at
a time and proving the resulting representative bound before changing the
recognizer.

* Proof and implementation obligations

Before =-tx bwd+loop= can be considered sound:

1. Formalize the one-fresh-process lemma for Cubicle's actual term, cube, and
   differentiated-variable semantics.
2. Prove that the syntactic footprint and self-disabling recognizer implies all
   assumptions of the lemma.
3. Prove coverage and precision of the generated cube family, including the
   fresh-variable distinctness case on small process domains.
4. Audit ordinary universal-guard instantiation at the exit; acceleration must
   consume its resulting cubes without inventing a second exit semantics.
5. Preserve the callee-tuple underscore semantics and its aliasing and
   distinctness regressions while integrating loops.
6. Add =bwd+loop= without changing the behavior of =bwd=, =fwd=, or =all=.
7. Preserve transaction-future substitutions and intermediate-cube naming.
8. Produce a replayable finite sequence of ordinary turns for an accelerated
   unsafe edge, or explicitly disable unsupported trace modes initially.
9. Reject unsupported loops, solver =unknown=, timeout, and failed recognition
   as diagnostics rather than =SAFE= or =UNSAFE=.

* Validation plan

1. *Mathematical examples.* Derive the generated predecessor families for zero
   named processes, one named process, several named processes, and domains with
   and without an additional process.
2. *Finite differential oracle.* For small domains, enumerate every state and
   every legal loop word, then compare the concrete starred predecessor with the
   generated finite cube family.
3. *Negative recognizer cases.* Reject a toggling local update, an incrementing
   global, a local-state-dependent shared write, cross-index interference, a
   universal loop guard, and a multi-process loop.
4. *Underscore regressions.* Check reuse of omitted caller arguments, pairwise
   distinctness within a multi-argument callee, and unary reuse across a loop or
   exit.
5. *German regression.* Run =examples/german_looped.cub= under =-tx bwd+loop=
   and compare small finite instances with explicit ordinary iteration.
6. *Mode isolation.* Confirm that the same input is rejected as unsupported
   under =-tx bwd=, =-tx fwd=, and =-tx all=.
7. *Project regression.* Run the complete =make test= suite and review all
   changed verdicts and diagnostics.

Finite-instance agreement is regression evidence for the implementation; it
does not replace the parameterized finite-relevance proof.

* Remaining design questions

The following do not block this proposal, but must be answered before or during
implementation rather than silently resolved in code:

- What is the smallest source-located representation of a loop marker and its
  retained transaction context?
- Should the first self-disabling recognizer be purely syntactic, or may explicit
  SMT validity checks establish its side conditions?  If SMT is used, =unknown=
  and timeout must reject the loop.
- Which existing subsumption operation is sound for reducing cube families with
  different variable sets, including the one-fresh branch?
- Which trace and certificate modes can replay an accelerated edge in the first
  implementation?

Any proposed relaxation of the transition class must first state its new
finite-relevance bound and exhibit either a proof or a counterexample.
